# 论文综述流水线

请按照以下标准流程，逐步执行论文综述的完整生产流水线。**每完成一步，将结果展示给用户确认后再进入下一步。**

## 流水线步骤

### 第一步：文献搜集（→ 存入 Zotero）
使用 `@literature-collector` 代理，根据用户的研究主题搜索相关论文，**并将论文存入 Zotero 文献库**。
- 搜索至少 3 个学术数据库
- 使用 zotero-mcp 的 `write_item` 工具将论文存入 Zotero
- 添加标签分类（如 "综述-2024"、"核心文献" 等）
- 输出已存入 Zotero 的论文列表（含 Zotero Key）

**请用户确认**：这些文献是否覆盖了研究方向？是否需要调整搜索策略？

### 第二步：文献吸收（从 Zotero 读取）
使用 `@literature-absorber` 代理，从 Zotero 中读取论文并进行分析。
- 使用 zotero-mcp 的 `search_library` 找到上一步存入的论文
- 使用 `get_content` 提取 PDF 全文
- 使用 `get_item_details` 获取元数据
- 逐篇输出结构化摘要，并保存为 Zotero 笔记

**请用户确认**：摘要是否准确？是否还需补充其他文献？

### 第三步：综述生成
使用 `@review-generator` 代理，基于文献摘要撰写综述。
- **先输出章节框架，等用户确认后再写正文**
- 按照确认的框架撰写完整综述
- 确保引用格式统一

**请用户确认**：框架和内容是否符合预期？

### 第四步：润色
使用 `@polisher` 代理，对综述全文进行语言润色。
- 改善学术表达和行文流畅度
- 统一术语和引用格式
- 输出润色后的全文 + 修改说明

**请用户确认**：润色效果是否满意？

### 第五步：审定
使用 `@auditor` 代理，对润色后的综述进行全面审查。
- 事实核查、逻辑检验、完整性评估
- 输出审定报告（严重/中等/轻微问题分级）
- 给出遗漏文献建议

**请用户确认**：是否接受审定意见？需要回到哪一步修改？

## 执行原则
- 每步完成后必须等待用户确认
- 用户可以在任何一步要求回退到之前的步骤
- 所有中间产物（文献列表、摘要、草稿、审定报告）保存到项目目录
